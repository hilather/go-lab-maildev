# LabMail 1.0.0-rc.3 Release Notes

Release date: 2026-08-20
Previous release: [v1.0.0-rc.2](https://github.com/hilather/go-lab-maildev/blob/v1.0.0-rc.2/docs/releases/v1.0.0-rc.2.md)
Application version: 1.0.0-rc.3
Configuration versions: labmail.dev/v1alpha1
REST versions: /v1
MCP protocol versions: 2026-07-28
Container digest: unpublished (Dockerfile is in-tree; `ghcr.io/hilather/labmail` is not pushed from this tag)

These notes are curated. They are not a commit list.

LabMail is a **receive-only lab sink**. It is **not** a public MTA and does **not** claim RFC 5321/5322 completeness. rc.3 is tagged only on a green CI SHA via the Release `tag-gate`.

Residual: [docs/known-limitations.md](https://github.com/hilather/go-lab-maildev/blob/v1.0.0-rc.3/docs/known-limitations.md).

## Highlights

Same product as rc.2: capture RFC 5321 SMTP and expose every accepted message over native REST `/v1`, Streamable HTTP MCP `/mcp`, maildev `/email` compat, and the embedded inbox SPA. Receive-only is unchanged.

What is new in rc.3:

- Operator-opt-in origin-policy hatches on the existing `spec.management.originAllowlist` field: sentinel `"*"` (any http(s) Origin) and `"private"` (Go `net.IP.IsPrivate()`: RFC 1918 + RFC 4193 ULA). Fixes the remote-dev / LAN inbox where `GET /` HTML is 200 but hashed Vite JS 403s (`origin is not allowed`) because module scripts send `Origin`. Production default stays `[]`. CORS / OPTIONS stay disabled. ADR 0008 / D18 / SEC-002.
- Confirmed defect fixes from the post-rc.2 deep review (#17): native `/relay` substring false-positive, spill List hiding missing files, DATA line-too-long closing the SMTP session, plan/apply idempotency ignoring `expectedRevision`/`force`, and management TLS setting `Secure` cookies without terminating TLS.
- Operator-facing README / START-HERE rewrite (YAML bootstrap and state APIs).

## Added

- `originAllowlist` sentinels `"*"` and `"private"` (quote `"*"` in YAML). Exact `http(s)://host[:port]` entries still work. Sentinels OR with exact entries. Adapters **live-read** the active snapshot (reset/restart pick up YAML; no apply op).
- ADR [0008](https://github.com/hilather/go-lab-maildev/blob/v1.0.0-rc.3/docs/adr/0008-origin-policy-escape-hatches.md). Cookbook: [docs/11-deployment.md](https://github.com/hilather/go-lab-maildev/blob/v1.0.0-rc.3/docs/11-deployment.md#origin-allowlist-cookbook). Example: [`examples/labmail.origin-dev.yaml`](https://github.com/hilather/go-lab-maildev/blob/v1.0.0-rc.3/examples/labmail.origin-dev.yaml) (quoted `"*"`, not the image default).
- Fail-closed validate on `originAllowlist` (cap 64; empty/glob/`file://`/`*/` rejected; `u.Hostname()` required). JSON Schema description + `maxItems: 64`.

## Changed

- README and START-HERE rewritten as an operator-facing front door: header art, a YAML bootstrap walkthrough, and curl/MCP examples for `GET /v1/state`, `POST /v1/state:validate`, `GET /v1/state:export`, `POST /v1/state:reset`, `POST /v1/changes:plan`, `POST /v1/changes:apply`.
- `"*"` in `originAllowlist` is now the any-http(s) sentinel (it was a no-op exact miss). Invalid entries that previously loaded are `validation_failed`.
- Origin allowlist is read from the live snapshot on every request (REST outer gate + MCP/compat inner). Bind-time copy is not the production SoT.

## Fixed

- Native `/v1/**/relay` is a path-segment guard. Message and attachment ids that only contain the substring `relay` are no longer `403 receive_only`.
- Inbox `List` returns `store.ErrSpill` when a recorded spill file cannot be read, matching `Get`/`Wait`. Missing spill files are no longer dropped from the page while `Stats` still counts them.
- `Get`/`Wait` re-check membership after spill I/O so a concurrent delete/wipe cannot return a message that is no longer in the store.
- A DATA line over 8192 octets replies `500` and aborts the transaction without closing the SMTP session (the codec drains through the terminating LF).
- Plan/apply idempotency fingerprints include `expectedRevision` and `force`, so a reused key with a different concurrency token is `idempotency_conflict`.
- `spec.listeners.management.tls.enabled` terminates TLS on the management listener (TLS 1.2+). Enabling it no longer set `Secure` cookies on a cleartext bind.
- Inbox UI ignores stale overlapping list responses and keeps a 15s list watchdog while SSE is open so dropped fan-out events cannot leave the page silent.
- Documented hatch for remote-dev / LAN SPA JS. Default empty list still 403s non-loopback hashed JS until hatched.

## Removed or deprecated

- None.

## Security

- Default `originAllowlist: []` is unchanged (present non-loopback Origin default-deny). Image / `examples/labmail.yaml` do **not** ship `"*"`.
- `"*"` turns off DNS-rebinding origin defense for all http(s) Origins. Keep `bearer_and_basic`. Do not put `"*"` on an unauthenticated management plane.
- `"private"` is every `net.IP.IsPrivate()` Origin host (RFC 1918 + ULA), not “this bind address.” RFC 6598 CGNAT / Tailscale `100.x` is **not** private; use exact or `"*"`.
- `dev-loopback-unauth` remains loopback `RemoteAddr` auth skip — not an origin hatch.
- CORS stays frozen: no `Access-Control-Allow-*`; `OPTIONS` is `403` `CORS is disabled` even with `"*"`.
- Receive-only, lab static bearer + optional Basic, MCP bearer-only, no OAuth PRM, preview CSP, file-referenced secrets: unchanged from rc.2.

## SMTP behavior

- Stock handshake is unchanged: [docs/02-smtp-semantics.md](https://github.com/hilather/go-lab-maildev/blob/v1.0.0-rc.3/docs/02-smtp-semantics.md).
- DATA line over 8192 octets is `500` and does not close the session.
- `spec.smtp.behavior` is unchanged from rc.2.

## Inbox UI

- Embedded SPA at `/` when `spec.ui.enabled` is true.
- Hashed Vite assets send `Origin` (`crossorigin` / module scripts). Empty allowlist 403s those GETs from a non-loopback browser origin; HTML navigation often does not.
- SSE list watchdog / stale-response ignore (post-rc.2 UI fix).

## Configuration and schema

- Existing field `spec.management.originAllowlist`. Published schema: [api/jsonschema/labmail.dev.v1alpha1.json](https://github.com/hilather/go-lab-maildev/blob/v1.0.0-rc.3/api/jsonschema/labmail.dev.v1alpha1.json).
- Stored entries are not rewritten (revision hash of a legal exact list is stable). Validate-tightening is an ADR 0008 exception to the additive-fields promise.
- No `replaceOriginAllowlist` apply op. YAML edit + reset or restart. Reset wipes the inbox.

## Deployment and operations

- Same CLI, ports 1025 / 1080, scratch image, UID 65532. Image digest still unpublished.
- Remote-dev: exact Origin, `"private"` (DHCP RFC1918/ULA), `"*"` (Codespaces / ephemeral DNS), or SSH/port-forward to loopback. Remote Vite without a proxy is not 1.0.

## Observability

- Unchanged catalog. Origin deny remains `capability=unknown` / `code_class=4xx` (gate runs before route match). Origin values are not added to slog records.

## Compatibility and migration

- From rc.2:
  - Additive sentinels on an existing field.
  - **Breaking for junk YAML:** entries that previously loaded (`file://`, host globs, empty strings, `"*/"`) now fail bootstrap / reset with `validation_failed`. Migration: replace them with exact `http(s)://host[:port]`, `"*"`, or `"private"`.
  - YAML that already contained `"*"` expecting a no-op exact miss now allows any http(s) Origin — review overlays.
- Rollback is process restart onto the previous pin. Captured mail is discarded on any restart.
- rc.2 documents with empty `originAllowlist` remain valid.
- maildev 2.2.1 deltas are unchanged (ULID, sha256, omitted list bodies, relay 403, no WebSocket).
- A later `v1.0.0` tag needs its own `docs/releases/v1.0.0.md` and a green `tag-gate`. **GA / 1.0 is not this rc.**

## Known limitations

See the durable list: [docs/known-limitations.md](https://github.com/hilather/go-lab-maildev/blob/v1.0.0-rc.3/docs/known-limitations.md).

- Not a complete / public MTA. No DSN, CHUNKING, advertised PIPELINING, Sieve, per-recipient quotas, or greylisting.
- Optional `spec.smtp.behavior` is deterministic and default-off — not a random chaos engine (D16).
- Empty `originAllowlist` still 403s non-loopback SPA JS until the operator hatches. `"*"` turns off rebinding origin defense. `"private"` is not CGNAT/Tailscale. No CORS.
- MIME parse of pathological messages may yield empty text/html with `parseWarning`; raw is still stored.
- Default `maxMessageBytes` is 10 MiB (maildev implicit ~50 MiB).
- No implicit SMTPS in 1.0.
- Compat `/email` ULID ids; list omits bodies; sha256 checksum; no WebSocket; relay is 403.
- Worst-case RSS ≈ 384 MiB. Single replica.
- MCP has no OAuth PRM. Catalog id stays `maildev` during the swap release.
- No published image digest, SBOM, or provenance on this candidate.
