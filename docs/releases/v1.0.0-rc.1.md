# LabMail 1.0.0-rc.1 Release Notes

Release date: 2026-08-18
Previous release: none (first public candidate; empty-tree baseline)
Application version: 1.0.0-rc.1
Configuration versions: labmail.dev/v1alpha1
REST versions: /v1
MCP protocol versions: 2026-07-28
Container digest: unpublished (DEP-001 image and digest pin are not in this tree)

These notes are curated. They are not a commit list.

LabMail is a **receive-only lab sink**. It is **not** a public MTA and does **not** claim RFC 5321/5322 completeness. rc.1 is tagged only on a green CI SHA via the Release `tag-gate`.

Residual: [docs/known-limitations.md](https://github.com/hilather/go-lab-maildev/blob/main/docs/known-limitations.md).

## Highlights

LabMail captures RFC 5321 SMTP from systems under test and exposes every accepted message over native REST `/v1`, Streamable HTTP MCP `/mcp`, maildev `/email` compat, and an embedded inbox SPA on `:1080`. It never opens an outbound SMTP session and never implements relay.

First-candidate decisions frozen here:

- License **Apache-2.0**
- Module **`github.com/hilather/go-lab-maildev`**
- Toolchain **Go 1.26**
- Binary **`labmail`**. Image name **`ghcr.io/hilather/labmail`** is reserved; this tree does not build or publish it.
- YAML **`labmail.dev/v1alpha1`**, kind **`LabMail`**
- MCP **2026-07-28** with TacLab `allowLegacyClients` knob (D17)
- Receive-only is structural (reserved YAML keys, no `Dial` in production SMTP/store/app, `POST /email/:id/relay` is 403)
- Inbox UI ships in this candidate (**Q2**: GA / 1.0 is not done without the inbox; the SPA is on this branch)
- Swap-release labinfo id stays **`maildev`** (D15 / Q1)

This file is the 1.0.0-rc.1 release notes. AUTH/STARTTLS, the hardened image, OBS metrics catalog, and swap overlay examples live on sibling branches and are **not** claimed as GA in this tree.

## Added

- Single static binary `labmail`: `serve`, `validate`, `canonicalize`, `healthcheck`, `version`, `help`, `mcp-stdio`.
- In-tree plain SMTP sink (`internal/smtp/{codec,server}`): greeting, HELO/EHLO, MAIL/RCPT/DATA/RSET/NOOP/QUIT/HELP, VRFY=252, EXPN=502, SIZE/8BITMIME/SMTPUTF8/ENHANCEDSTATUSCODES, session and in-flight DATA caps. Interop: `net/smtp.SendMail` against localhost.
- Fail-closed `labmail.dev/v1alpha1` YAML: `KnownFields(true)`, reserved relay-key reject, default materialization, canonical `sha256:` revision.
- Bounded memory inbox: Crockford ULID ids, MIME via `internal/mimeparse`, stacked resident caps, `fullPolicy: reject` → SMTP 452, Wait + timeout, Wipe epoch (stale Insert → 451). Malformed MIME is still stored.
- HTTP-less `internal/app.Service`: atomic snapshot, plan/apply, reset that rereads YAML and wipes the inbox.
- Native REST `/v1`: problem+json, HMAC list cursors, wait/extract (frozen RE2), preview CSP + `cid:` → `data:`, plan/apply, health/ready, generated OpenAPI and capability manifest.
- Streamable HTTP MCP at `POST /mcp`: official SDK `v1.7.0`, protocol `2026-07-28`, `mail_*` tools, `labmail://` resources, `make test-parity`.
- maildev 2.2.1 compat: `GET /email` JSON array (bodies omitted), get/delete/html/attachment, `/healthz`, redacted `/config` (`receiveOnly: true`). Relay is always 403.
- Lab static bearer + HTTP Basic onto the same principal. MCP is bearer-only. `TestMaildevScenarioCompat` (SendMail + 401 + Basic subject). Session cookie `labmail_session` + `X-LabMail-CSRF`.
- Embedded inbox SPA (React/TS + Vite, Node **22.14.0**): login, list, sandboxed HTML preview, status, scoped audit, gated reset. No Relay/send/compose.
- GA-001: committed fuzz corpora, `internal/perf` soak (accept N, wait, wipe), this notes file, [docs/known-limitations.md](https://github.com/hilather/go-lab-maildev/blob/main/docs/known-limitations.md), changelog check, Release `tag-gate`.

## Security

- Receive-only: no SMTP client; reserved YAML keys; import-boundary tests; `POST /email/:id/relay` is 403 `receive_only`.
- Default management auth is `bearer_and_basic`. Unauthenticated `GET /email` is 401. MCP is bearer-only. No OAuth PRM.
- `X-Forwarded-For` is not trusted. Present non-loopback `Origin` is default-deny; missing Origin is allowed.
- HTML preview: iframe `sandbox` without scripts/same-origin; CSP `default-src 'none'; img-src data:; style-src 'unsafe-inline'`; `cid:` inlined as `data:`; download route is `Content-Disposition: attachment`.
- Secrets are file references, never inline (except optional `LABMAIL_ALLOW_ENV_SECRETS=1` dev). Export/audit/logs redact token values and SMTP passwords.
- `make security-scan` runs govulncheck. The container posture (UID 65532, scratch, no caps) is DEP-001 and is not in this tree.

## SMTP behavior

- Banner: `220 <hostname> LabMail ready`. The banner does not contain “maildev”.
- Commands and limits: [docs/02-smtp-semantics.md](https://github.com/hilather/go-lab-maildev/blob/main/docs/02-smtp-semantics.md). This tree implements the SMTP-001a slice only.
- AUTH and STARTTLS are **not** implemented. Compiled YAML that asks for them fail-closes at `serve` / live apply / reset until SMTP-001b stacks.
- Implicit SMTPS remains a validate reject (1.1).
- Successful DATA replies `250 2.0.0 Queued as <ULID>`. Empty `MAIL FROM:<>` is accepted.
- This is a lab capture sink. It does not resolve MX, open outbound TCP, rewrite recipients, or generate DSNs.

## Inbox UI

- Embedded at `/` when `spec.ui.enabled` is true (default). `enabled: false` 404s `/` and keeps REST/MCP.
- Login via bearer or Basic → `POST /v1/session`. Cookie is REST-only.
- Pages: inbox list, message view (text / sandboxed HTML preview / headers / raw / attachments), status, scoped audit, gated reset.
- Live update: `EventSource` `GET /v1/events/stream` with a 3s poll fallback. No maildev WebSocket.
- No Relay, send, outgoing settings, or compose. Required for GA / 1.0 (Q2); present in this candidate.

## REST API

- stdlib `net/http` adapter on the management listener (default `:1080`). OpenAPI: [api/openapi/v1.json](https://github.com/hilather/go-lab-maildev/blob/main/api/openapi/v1.json). Capability table: [api/capabilities/v1.json](https://github.com/hilather/go-lab-maildev/blob/main/api/capabilities/v1.json).
- Errors are `application/problem+json`. Domain `code` is first-class (`cursor_stale`, `store_over_new_cap`, `receive_only`, …).
- Native `GET /v1/messages/{id}` defaults `markRead=false`. Compat `GET /email/:id` marks read (maildev).
- Health live/ready skip auth. Ready requires SMTP bound and (management bound or explicitly off).

## MCP API and protocol compatibility

- Pinned protocol **2026-07-28**. Manifest: [api/mcp/v1.json](https://github.com/hilather/go-lab-maildev/blob/main/api/mcp/v1.json).
- Official SDK `github.com/modelcontextprotocol/go-sdk v1.7.0`. Streamable HTTP at `/mcp` is stateless.
- `spec.management.mcp.allowLegacyClients` default **false** (lab overlay sets true). `subscriptions/listen` stays 2026-07-28 even when the pin is relaxed.
- Tools and `labmail://` resources come from the shared registry. Native `mail_message_get` defaults `markRead=false`.
- Stdio is a developer adapter (`labmail mcp-stdio --token-file`) and is not an image entrypoint.

## Configuration and schema

- Strict v1alpha1 decode in `internal/config`. Published schema: [api/jsonschema/labmail.dev.v1alpha1.json](https://github.com/hilather/go-lab-maildev/blob/main/api/jsonschema/labmail.dev.v1alpha1.json).
- Unknown fields, YAML aliases, multi-doc streams, bare numbers, reserved relay keys, `maxMessageBytes: 0`, and `smtp.tls.mode: implicit` fail closed.
- Canonical export materializes defaults and drops comments. Revision is `sha256:` of canonical JSON. Inbox contents do not set `drifted`.
- Reset rereads the bootstrap path (never writes it) and wipes the inbox (only epoch bump).

## Deployment and operations

- `labmail serve --config PATH` compiles bootstrap and binds SMTP (default `:1025`) plus management (default `:1080`). `--management-listen=off` leaves management unbound. `SIGTERM` is graceful; `SIGUSR1` is unused.
- Image `ghcr.io/hilather/labmail` is **not** built from this tree (DEP-001). Host ports stay 1025 / 1080 when that image exists.
- Required CI jobs have no bypass. Tag path is the Release workflow `tag-gate` only.
- `make test-container` is fail-closed until DEP-001. Soak: `go test ./internal/perf` (default N=8).

## Compatibility and migration

- First install only. There is no predecessor application tag.
- Pin config `apiVersion: labmail.dev/v1alpha1`. Unknown fields fail closed.
- MCP clients must speak `2026-07-28` unless `allowLegacyClients: true`.
- Rollback is process restart onto a previous desired-state pin. Captured mail is discarded on any restart.
- maildev 2.2.1 `/email` read/delete shape is best-effort; relay will never work. ULID ids, sha256 checksums, omitted list bodies, and no WebSocket are documented deltas.
- A later `v1.0.0` tag needs its own `docs/releases/v1.0.0.md` and a green `tag-gate`. **GA / 1.0 is not this rc** and still requires the inbox UI (already here) plus stacked DEP/OBS/SWAP (and SMTP-001b before any AUTH/STARTTLS claim).

## Known limitations

See the durable list: [docs/known-limitations.md](https://github.com/hilather/go-lab-maildev/blob/main/docs/known-limitations.md).

- Not a complete / public MTA. No DSN, CHUNKING, PIPELINING, Sieve, per-recipient quotas, or greylisting.
- MIME parse of pathological messages may yield empty text/html with `parseWarning`; raw is still stored.
- Default `maxMessageBytes` is 10 MiB (maildev implicit ~50 MiB).
- No implicit SMTPS in 1.0. AUTH/STARTTLS are not implemented in this tree.
- Compat `/email` ULID ids; list omits bodies; sha256 checksum; no WebSocket; relay is 403.
- Worst-case RSS ≈ 384 MiB (256 MiB stored + 64 MiB in-flight + ~64 MiB slack). Single replica.
- MCP has no OAuth PRM. Catalog id stays `maildev` during the swap release.
- No tag, image digest, SBOM, or provenance in this candidate. Default soak is 8 messages.
